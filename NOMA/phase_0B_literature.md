# Phase 0B — Literature & Gap Matrix

## Output
- `Literatures/` — verified source PDFs (or DOI-confirmed records)
- `Manuscript/references.bib` — BibTeX database with DOI-verified entries
- `literatures_inventory.json` — machine-readable inventory of all sources
- `docs/Gap_Matrix.md` — structured literature gap analysis

## Target
Minimum **20 verified references** covering: NOMA fundamentals, network slicing, unsupervised ML in networking, SimPy simulation methodology, and 5G/B5G resource management. At least 60% published 2019–2024 (recency requirement for IEEE Communications Letters).

## Entry Condition
- Gate 1 passed: `docs/IEEE_CommLetters_Guidelines_Extract.md` exists and is verified
- `Manuscript/templates/` is non-empty

## Exit Check
```powershell
# Check 1: references.bib exists and has entries
(Select-String -Path "Manuscript\references.bib" -Pattern "@").Count -ge 20

# Check 2: literatures_inventory.json exists
Test-Path "literatures_inventory.json"

# Check 3: Gap matrix exists
Test-Path "docs\Gap_Matrix.md"

# Check 4: Run citation checker
python scripts\citation_checker.py
# Expected: 0 entries with missing DOI flagged as unresolvable
```

## Characteristic Failure Mode
**Do not cite papers from memory or from titles-only searches.**
Every reference must have a verified DOI that resolves, OR a PDF physically in `Literatures/`. The quarantine files (`Literatures_quarantine/`) contain citations in the format `(Shah et-al., 2021)` — these are author-year style and lack DOIs. Each must be resolved individually:
1. Search the title + authors on Google Scholar / Semantic Scholar
2. Confirm the DOI resolves
3. Download the PDF if open-access
4. Add the BibTeX entry to `references.bib`
5. If unresolvable → move to `Literatures_quarantine/` and remove the citation from the draft

### Step 3 — BibTeX database
`Manuscript/references.bib` — IEEE numbered format compatible. Each entry must contain:
- `author`, `title`, `journal`/`booktitle`, `year`, `doi`, `pages`/`volume`/`number` where applicable
- No entry without a confirmed DOI is permitted (mark as `[NEEDS_DOI]` and log in OI)

### Step 4 — Inventory JSON
